# Code of Conduct

We want participation in this project to be welcoming, respectful, and harassment-free for everyone.

Expected behavior includes respectful communication, constructive feedback, and consideration for different viewpoints and experiences.

Harassment, discrimination, personal attacks, trolling, unwanted sexual attention, publishing private information, and other inappropriate conduct are not acceptable.

Report unacceptable behavior privately to the project maintainer through the repository maintainer’s GitHub profile. Reports will be handled as confidentially as practical, and maintainers may remove content or restrict participation when necessary.
